## 💡 Why PostCraft AI?

Creating daily corporate social media graphics usually requires:
- Expensive graphic design software subscriptions (Canva Pro, Adobe Photoshop).
- Prompt-heavy AI image tools (Midjourney, DALL-E) that **frequently hallucinate gibberish spelling**, miss exact branding guidelines, and cannot align precise corporate typography.
- Manual copy-pasting of phone numbers, website links, brand logos, and disclaimers.

**PostCraft AI solves this completely**:
- **Real Typography on HTML5 Canvas**: Every headline, body sentence, and bullet point is drawn as sharp, genuine vector text. No spelling errors, no blurry artifacts.
- **50 Bespoke Vector Templates**: Not repetitive cookie-cutter layouts. Every template features custom vector illustrations (speedometer gauges, 3D book mockups, web dashboards, device pedestals, festive elements).
- **Brand Automation**: Sets company logo, website URL, phone number, and primary brand colors (`#008080` Infinitetech Teal) across every graphic automatically.
- **100% Free & Fast**: Generates complete copy, hashtags, captions, and 1200×1200px graphics in milliseconds directly in the browser.

## ✨ What It Does (Core Capabilities)

When you input a topic or job title (e.g., *"Senior Cloud Architect"* or *"Copilot+ AI Solutions"*):
1. **Generates High-Impact Copy**:
   - **Poster Headline**: High-contrast, punchy hook designed for social engagement.
   - **Tagline / Subtitle**: Executive-level context.
   - **Key Deliverables / Specs / Features**: 3 to 4 structured data points.
   - **Call-to-Action (CTA)**: High-converting action button text.
   - **Social Caption & Hashtags**: Formatted caption with 5+ industry hashtags, ready to copy-paste directly to LinkedIn or Instagram.
2. **Renders Professional Graphics**:
   - Generates pixel-perfect graphics at standard social resolutions (1200×1200 Square, 1200×627 Landscape, 1080×1350 Portrait).
   - Dynamically measures text with automatic multi-line wrapping and font auto-scaling to prevent truncation or overflow.
   - Embeds user-uploaded background images or renders vector art automatically when no image is provided.
3. **One-Click Export**:
   - Download high-res PNG or JPEG files.
   - Copy image directly to system clipboard.
   - Export bulk batches as a single ZIP file or CSV scheduling sheet.

## 📱 Application Modules

The app is organized into **6 core navigation views**:

## 🤖 AI Generation Engine

PostCraft AI supports multiple AI backends to fit any workflow:

1. **Built-in Offline Engine (*Zero Config*)**:
   - High-quality, domain-specific rule generator covering 15+ business verticals.
   - Works 100% offline without needing any API key or server.
2. **Groq Cloud API (*Fastest Cloud LLM*)**:
   - Ultra-fast responses powered by Llama 3 / Mixtral models.
   - Enter your Groq API key in **Settings** or `.env.local`.
3. **Ollama Local AI (*Private & Offline*)**:
   - Connects to Ollama running locally at `http://localhost:11434`.
   - Supports `llama3`, `mistral`, `phi3`, and custom local models.
4. **Pollinations AI (*Free Image Generation*)**:
   - Generates contextual topic photos when users request AI-generated imagery.

## 🚀 Getting Started (Windows & Cross-Platform)

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (Version 18.x or higher)
- npm (bundled with Node.js)

Verify your installation in PowerShell or Terminal:
```powershell
node -v
npm -v
```

### 2. Installation
Clone or navigate to the project root directory:
```powershell
cd "c:\Users\katana\Downloads\media handling"
npm install
```

### 3. Start Development Server
```powershell
npm run dev
```
The server will start at:
👉 **`http://localhost:5173`**

### 4. Build for Production
To test or deploy an optimized production bundle:
```powershell
npm run build
```
The output will be placed in the `dist/` directory.

To preview the built production site locally:
```powershell
npm run preview
```

## ⚙️ Configuration & Environment Variables

Create or edit `.env.local` in the project root to configure optional cloud AI providers:

```env
# Optional: Groq Cloud API Key for ultra-fast Llama-3 generation
VITE_GROQ_API_KEY=your_groq_api_key_here

# Optional: Custom Ollama endpoint (Default: http://localhost:11434)
VITE_OLLAMA_BASE_URL=http://localhost:11434
```

> **Note**: An API key is **not required** to use the application. If no key is provided, PostCraft AI uses its built-in rule and template generator.

## ❓ Troubleshooting & FAQ

### Q1: The browser shows "Port 5173 is in use"?
Vite will automatically fall back to the next available port (e.g., `http://localhost:5174`). Check your terminal output for the active URL.

### Q2: How do I change the default company logo or contact details?
Go to the **Brand Settings** tab in the sidebar. You can upload a new PNG/SVG logo, update company name, website URL, and phone number. Changes persist across all 50 templates automatically.

### Q3: How do I connect Ollama locally?
1. Install [Ollama](https://ollama.ai/).
2. Run `ollama pull llama3` in your terminal.
3. Start the Ollama daemon with CORS allowed:
   ```powershell
   $env:OLLAMA_ORIGINS="*"
   ollama serve
   ```
4. In PostCraft AI, go to **Settings** and toggle **Enable Ollama**.

### Q4: Why don't generated posters have spelling mistakes?
Unlike generative diffusion models that attempt to "draw" text as pixels, PostCraft AI uses **native HTML5 2D Canvas vector typography**. Every character is rendered cleanly using system and web fonts with mathematical line wrapping, guaranteed 100% correct spelling.
